# NASA Global Challenge / Space Apps Deliverables

This directory contains official submission materials, presentation slides, video demonstration assets, and project notes for TerraScope.

## Deliverables Checklist (Section 21)

- [x] **Repository Structure**: Monorepo with separated `frontend/`, `backend/`, and `docs/`.
- [x] **Architecture & Methodology**: Formally documented in `docs/architecture.md` and `docs/methodology.md`.
- [x] **Sample Datasets**: Offline verification datasets in `data/sample/`.
- [ ] **Slide Presentation**: 7-slide pitch deck placed in `challenge/presentation/`.
- [ ] **Demonstration Video**: 30–60 second walkthrough video placed in `challenge/demo_video/`.
- [x] **Submission Notes**: Comprehensive project description in `challenge/submission_notes.md`.
